# fpsuppliers

Телеграм-бот и админка для реселлеров цифровых товаров: база поставщиков, каталог товаров,
сравнение цен, расчёт маржи и сканер связок «купить дешевле → продать дороже».

- `server/` — API, телеграм-бот и фоновые задачи (Node.js + Express + PostgreSQL + Redis)
- `admin/` — веб-админка (HTML + vanilla JS + CSS по БЭМ, без сборки)
- `docs/` — документация: [запуск](docs/devs/setup.md), [архитектура](docs/devs/architecture.md),
  [API](docs/devs/api.md), [эксплуатация](docs/devs/runbook.md), [для пользователей](docs/users/getting-started.md)

Быстрый старт — [docs/devs/setup.md](docs/devs/setup.md).
