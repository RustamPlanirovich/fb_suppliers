# Changelog

> Обновлено: 2026-08-21

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [Unreleased]

### Добавлено

- Телеграм-бот: поиск товара, карточка связки «поставщик → товар → площадка → прибыль»,
  сравнение цен «где дешевле», история цены, калькулятор прибыли, избранное, watchlist,
  условные алерты, кабинет реселлера, кнопка «неактуально / проблема», заявки
  «предложить поставщика» и «найди поставщика».
- Админка: дашборд, реестр поставщиков с фильтрами и массовыми действиями, поиск и объединение
  дублей, каталог товаров и вариантов, предложения с историей цены, сканер связок, очередь
  контроля данных, очереди модерации, пользователи бота, конструктор тарифов, реклама
  и размещение в топе, контент бота и FAQ, рассылки, аналитика рынка, импорт и экспорт Excel/CSV.
- Расчёт связок: прибыль, ROI, маржа, свежесть цены, уровень конкуренции и риска.
- Автофлаги контроля данных: скачки и аномалии цен, устаревшие цены и проверки, много жалоб.
- История изменений: кто, когда, что и на основании чего поменял; правка цены требует
  указания источника и доказательства.
- Гибкие тарифы: набор возможностей собирается администратором.
- Наполнение базы из разделов площадки: поиск игры и раздела в админке, предпросмотр с разбивкой
  на варианты и ценами, загрузка товаров, вариантов, карточек продавцов и их цен одним действием.
- Разделы площадки можно сохранить на автообновление — цены обновляются фоновой задачей.
- Разбиение раздела на варианты по фильтрам площадки, а для разделов без фильтров — по правилам
  из названия предложения.

### Добавлено (продолжение)

- Раздел «Что выгодно прямо сейчас» в аналитике: готовые вопросы (выгодно продавать,
  выгодно покупать, растёт спрос, цена падает) плюс фильтры по марже, прибыли, конкуренции,
  числу продавцов и поставщиков, тренду цены — с сортировкой по любому из этих признаков.
- Возможность тарифа «Аналитика рынка»: команда `/market` в боте отдаёт ту же витрину
  подписчикам; на тарифах Free и Pro закрыта.

### Добавлено (поиск)

- Поиск понимает разные написания одного товара: регистр, пробелы, кириллицу и латиницу,
  сокращения и опечатки. «YOUTUBE», «ютуб», «ют», «ютьюб» находят один товар; «гпт»,
  «чат гпт», «чатгпт» — другой.
- Словарь синонимов у товара: автоматические собираются из названия, свои добавляет
  администратор в разделе «Товары» → «Синонимы».
- Из экрана «Ищут, но у нас нет» запрос привязывается к товару одной кнопкой и сразу
  перестаёт быть пустым.

### Добавлено (бот)

- Навигация по каталогу: «📂 Категории» → раздел → подраздел → список поставщиков с листанием.
- Кнопка «➡️ Перейти к поставщику» — открывает его напрямую (Telegram, площадка или сайт).
- Кнопка «📋 Показать всех» под выдачей поиска: полный список поставщиков по позиции,
  от самой низкой цены, страницами по 8.
- Дерево категорий создаётся само при загрузке раздела площадки: игра → раздел.

### Изменено

- Поставщик относится к категории по своим предложениям, а не по полю в карточке:
  один поставщик торгует в разных разделах, и ручная разметка для навигации больше не нужна.
- Страница «Товары» сгруппирована по товарам: строка товара показывает сводку по всем
  своим вариантам и разворачивается по клику. Добавлена сортировка по марже, числу
  предложений и поставщиков, цене закупки, спросу и числу вариантов.

- Админка переоформлена в тему «матовое стекло»: плавающие панели, рельс разделов с иконками,
  поиск в шапке, дашборд из двух колонок — витрина связок, график активности и лента изменений
  цен слева, сводка показателей справа.

### Исправлено

- Валюта витрины площадки фиксируется явно: без этого один и тот же раздел приходил то в рублях,
  то в евро, и расчёт маржи был неверным. При неожиданной валюте синхронизация останавливается.
- Загрузка раздела площадки разбивала предложения на варианты не так, как показывал предпросмотр.
- Синхронизация площадки не записывала историю цен — график цены по таким предложениям был пуст.
- Поля форм наезжали друг на друга: не был задан `box-sizing`.
- Поиск в боте ставил выше вариант с двумя предложениями вместо варианта с сотнями —
  короткое название получало больший вес при ранжировании.
- Очередь проверки заполнялась только что импортированными карточками.
- Подпись раздела в меню пряталась под рабочей панелью: `backdrop-filter` создаёт контекст
  наложения, панель перекрывала рельс.
- Фильтр сортировки показывал не то значение, по которому список уже отсортирован.

### Безопасность

- Контакты продавцов площадки не собираются и не хранятся — ограничение на уровне БД (ADR 0004).
- Массовая рассылка на 500+ получателей требует явного подтверждения точного охвата.
- Сессии администраторов в Redis, `httpOnly`-кука, лимиты на вход и на API.
