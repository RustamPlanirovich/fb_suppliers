# Runbook

> Обновлено: 2026-08-21

Первый запуск и переменные окружения — в [setup.md](setup.md), здесь только эксплуатация.

## Окружение

| Что | Где |
|---|---|
| Процесс | pm2, имя `fpsuppliers`, конфиг `server/ecosystem.config.cjs` |
| БД | PostgreSQL, база и роль `fpsuppliers` |
| Кэш и сессии | Redis |
| Админка | статика `admin/src`, раздаётся nginx |

## Деплой

```bash
cd server
git pull
npm ci
npm run migrate            # применяются только новые миграции
pm2 reload ecosystem.config.cjs --env production
pm2 logs fpsuppliers --lines 50
```

Админка выкладывается копированием `admin/src` в корень статики; сборка не нужна.
После деплоя проверить `curl -s https://<домен>/health`.

## Логи

Структурные JSON-строки, одна запись на строку: `pm2 logs fpsuppliers`.
Уровень задаётся `LOG_LEVEL`. Полезные поля: `component` (`bot`, `broadcasts`, `alerts`,
`scheduler`, `funpay`, `audit`), `job` для фоновых задач.

## Бэкапы и восстановление

```bash
pg_dump -Fc -U fpsuppliers fpsuppliers > /backup/fpsuppliers-$(date +%F).dump   # ежедневно
pg_restore -c -U fpsuppliers -d fpsuppliers /backup/fpsuppliers-2026-08-21.dump
```

Redis не резервируется: всё в нём восстанавливается из PostgreSQL. Потеря Redis выкидывает
администраторов из админки и сбрасывает суточные квоты поисков.

## Регулярные операции

- Очередь проверки: раздел «Контроль данных» → «Просканировать», затем разобрать флаги.
- Пополнение базы: «Аналитика рынка» → «Ищут, но у нас нет» — список того, чего не хватает.
- Пересчёт связок вручную: «Связки» → «Пересчитать» (обычно делает планировщик).

## Известные проблемы

**Симптом:** бот не отвечает, в логах `Телеграм-бот отключён`.
**Причина:** не задан `TELEGRAM_BOT_TOKEN` или `BOT_ENABLED=off`.
**Действия:** заполнить переменную, `pm2 reload`.

**Симптом:** `409 Conflict` от Telegram при старте.
**Причина:** запущены два процесса с одним токеном (например, локальный и продовый).
**Действия:** оставить один; локально ставить `BOT_ENABLED=off`.

**Симптом:** рассылка «зависла» в статусе `sending`.
**Причина:** процесс перезапущен во время отправки; блокировка в Redis держится до часа.
**Действия:** дождаться снятия блокировки или удалить ключ `fpsuppliers:broadcast:lock:<id>`,
затем запустить рассылку заново — уже отправленные адресаты повторно не получат сообщение.

**Симптом:** синхронизация площадки возвращает `SYNC_DISABLED`.
**Причина:** `FUNPAY_SYNC_ENABLED` не равен `on`.
**Действия:** включить осознанно; парсер обращается к площадке последовательно с паузой.

**Симптом:** синхронизация раздела падает с «Площадка отдала цены в EUR, ожидалось RUB».
**Причина:** площадка не приняла cookie валюты или сменила её обработку.
**Действия:** проверить `FUNPAY_CURRENCY`; если проблема повторяется — сверить механизм
переключения валюты на сайте и поправить `funpay.client.js`. Данные в базу при этом не попадают.

**Симптом:** синхронизация возвращает «не найдено ни одного предложения».
**Причина:** площадка сменила вёрстку или раздел пуст.
**Действия:** открыть страницу раздела в браузере; если предложения есть — поправить селекторы
в `server/src/components/funpay/funpay.selectors.js`, разбор и логика синхронизации не меняются.

**Симптом:** после загрузки раздела в каталоге пусто, маржа не считается.
**Причина:** карточки загружены со статусом «на проверке», а связки строятся только по проверенным.
**Действия:** «Поставщики» → фильтр «На проверке» → выделить → «Проверен»; либо загружать
раздел сразу со статусом «Проверен».

**Симптом:** любой запрос к API отвечает 500, в логах `could not write to file`.
**Причина:** на диске не осталось места — PostgreSQL не может писать временные файлы.
**Действия:** освободить место на разделе с данными БД, затем `VACUUM ANALYZE`.
Проверка: `df -h /System/Volumes/Data` (macOS) или `df -h /var/lib/postgresql` (Linux).

**Симптом:** в разделах «Выгодно покупать» и «Цена падает» пусто.
**Причина:** тренд считается по истории цен за 7 дней, а история только начала накапливаться.
**Действия:** подождать неделю регулярных синхронизаций; остальные вкладки работают сразу.

**Симптом:** после правок цен маржа в админке не изменилась.
**Причина:** агрегаты пересчитываются фоновой задачей раз в 15 минут.
**Действия:** «Товары» → «Пересчитать статистику».

**Симптом:** ошибка `VALIDATION` при сохранении контактов поставщика.
**Причина:** источник карточки — площадка, контакты для неё запрещены (ADR 0004).
**Действия:** если поставщик независимый — сменить источник на `telegram`/`manual`.
