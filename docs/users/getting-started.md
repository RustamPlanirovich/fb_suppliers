# Начало работы

> Обновлено: 2026-08-21

Бот помогает перепродавать цифровые товары: показывает, где купить дешевле, за сколько это
продаётся и сколько вы заработаете.

## Два способа найти поставщика

**По категориям.** Нажмите «📂 Категории» — выберите раздел, затем подраздел, и бот покажет
всех поставщиков этого направления. Рядом с названием раздела указано, сколько их там.
Длинные списки листаются кнопками «⬅️ ➡️».

**Поиском.** Отправьте название товара сообщением — например, «Spotify Premium». Если у товара
есть варианты (1 месяц, 12 месяцев), выберите нужный. Бот покажет карточку позиции,
самые дешёвые предложения и кнопку «📋 Показать всех», если поставщиков больше.

Под каждой карточкой есть кнопка **«➡️ Перейти к поставщику»** — она открывает его сразу,
без промежуточных шагов.

## Что в карточке предложения

- **Поставщик** и **цена закупки**.
- **Средняя цена продажи** на площадке и **комиссия** площадки.
- **Чистая прибыль** и **ROI** — сколько вы заработаете с одной штуки.
- **Надёжность** поставщика и число подтверждённых покупок за 30 дней.
- **Свежесть цены** — когда её проверяли в последний раз.

## Кнопки под карточкой

| Кнопка | Что делает |
|---|---|
| ➡️ Перейти к поставщику | Открывает поставщика напрямую |
| 📇 Контакты | Показывает контакты, если прямой ссылки нет |
| ⭐ В избранное | Сохраняет поставщика в ваш список |
| 📉 История цены | Показывает, как менялась закупочная цена |
| 🧮 Калькулятор | Считает прибыль по этому предложению |
| 👁 Отслеживать | Добавляет позицию в отслеживаемые |
| 🔔 Алерт | Подсказывает, как настроить уведомление |
| ⚠️ Неактуально / проблема | Сообщает нам, что с поставщиком что-то не так |

## Команды

| Команда | Что делает |
|---|---|
| `/categories` | Каталог по категориям |
| `/deals` | Что сейчас выгодно перепродавать |
| `/favorites` | Избранные поставщики |
| `/watchlist` | Отслеживаемые позиции |
| `/alerts` | Ваши уведомления |
| `/calc 650 990 10` | Расчёт: закупка, продажа, количество |
| `/positions`, `/pos Название 650 990 10` | Ваши сделки и прибыль |
| `/add Название, контакт, что продаёт` | Предложить поставщика |
| `/price <id предложения> <цена>` | Сообщить о новой цене |
| `/find Нужен товар X до 400 ₽` | Заявка на поиск поставщика |
| `/plans` | Тарифы |

## Важно про площадки

Цены площадок показаны справочно. Сделки проводятся внутри самих площадок по их правилам —
бот не помогает уводить покупателей за пределы площадки.
