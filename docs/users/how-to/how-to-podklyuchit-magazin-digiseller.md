# Как подключить магазин Digiseller

> Обновлено: 2026-08-21

## Что получится

Товары магазина с plati.market попадут в базу как позиции поставщика: с ценами, ссылками
на конкретные товары и обновлением по расписанию.

## Где взять ID продавца

Поле принимает любой из трёх вариантов — искать числовой ID вручную не нужно:

| Что вставить | Пример |
|---|---|
| Ссылку на любой товар магазина | `https://plati.market/itm/chatgpt/5988103` |
| Ссылку на сам магазин | `https://plati.market/seller/1397753` |
| Числовой ID продавца или товара | `1397753` или `5988103` |

Если вставить ссылку на товар, подтянется и настоящее имя продавца — например, `nauk0a`.

## Шаги

1. Откройте раздел «Источники цен».
2. В поле «Площадка» выберите **Digiseller**.
3. Вставьте ссылку или ID и нажмите «Найти».
4. Выберите раздел: у магазина это его категории либо «Весь каталог».
5. Нажмите «Посмотреть, что там» и проверьте разбивку.
6. У Digiseller нет фильтров площадки, поэтому всё попадёт в один вариант. Разложите товары
   правилами по названию, например:
   ```
   ChatGPT = chatgpt|gpt
   Почты = mail|почт
   ```
7. Нажмите «Загрузить в базу», при желании — «Сохранить раздел на автообновление».

## Если что-то пошло не так

- **«Не найдено»** — магазин пуст или ID неверный. Проверьте, открывается ли ссылка на товар
  в браузере.
- **Всё попало в один вариант** — правила не заданы или не сработали: проверьте, что подстрока
  действительно встречается в названиях товаров.
